# إعداد مزوّدات الذكاء الاصطناعي المجانية في JobFinder

## سياسة التكلفة

**JobFinder مضبوط ليستخدم مسارات مجانية فقط. لا يستدعي OpenAI API ولا يختار نماذج OpenRouter المدفوعة.**

ترتيب التحليل والمراجعة المستقلة لقرارات APPLY:

1. **Gemini API — فئة Flash المجانية:** المسار الأساسي. يسمح الكود فقط بـ `gemini-3.8-flash` ثم `gemini-3.7-flash` ثم `gemini-3.6-flash`، وهي نماذج تظهر لها أسعار Free Tier بقيمة صفر في صفحة Google الرسمية. أي اختيار لنموذج Pro أو اسم غير موجود في القائمة يُرفض/يُتجاهل.
2. **Groq — Free tier:** مسار احتياطي. يستخدم JobFinder واجهة Groq فقط؛ أسماء بعض النماذج تبدأ بـ `openai/` لأنها نماذج OpenAI مفتوحة الأوزان مستضافة على Groq. هذا لا يعني استخدام OpenAI API أو دفع رسوم إلى OpenAI.
3. **OpenRouter — Free:** المسار الأخير. يضبط الكود النموذج على `openrouter/free`، ويرفض أي نموذج مدفوع. لا تمرّر متغير نموذج من GitHub Actions.

عند نفاد الحصة أو تعذّر الخدمات المجانية، يحفظ JobFinder حالة التوقف ويؤجل إعادة المحاولة. لا ينتقل إلى OpenAI أو إلى نموذج OpenRouter مدفوع.

## تنبيه مهم بشأن الحسابات

المستودع لا يستطيع تغيير خطة الفوترة في حسابات المزودين. حتى تبقى التكلفة صفرًا:

- استخدم مشروع Gemini في **Google AI Studio Free tier** ولا تربطه بخطة مدفوعة أو فوترة.
- أبقِ حساب Groq على **Free plan** ولا ترقّه إلى Developer plan ولا تضف وسيلة دفع.
- استخدم OpenRouter Free فقط؛ لا تشترِ أرصدة.

تختلف حدود الطلبات والنماذج المتاحة حسب المزود والحساب والمنطقة. عند بلوغ الحد المجاني، من الطبيعي أن يتوقف JobFinder مؤقتًا بدل الدفع مقابل طلبات إضافية.

## أسرار GitHub المطلوبة

من **Repository → Settings → Secrets and variables → Actions**:

| الاسم | النوع | الغرض |
|---|---|---|
| `GEMINI_API_KEY` | Secret | المسار الأساسي المجاني من Gemini |
| `GROQ_API_KEY` | Secret | المسار الاحتياطي على Groq Free |
| `OPENROUTER_API_KEY` | Secret، اختياري | المسار الأخير OpenRouter Free |

لا يحتاج JobFinder إلى `OPENAI_API_KEY` أو `OPENAI_MODEL` أو `OPENAI_REVIEW_MODEL` أو `GEMINI_REVIEW_MODEL` أو `GEMINI_MODEL` أو `GEMINI_FALLBACK_MODELS` أو `OPENROUTER_MODEL` في بيئة التشغيل. ولا تستطيع متغيرات النماذج تغيير قائمة Gemini المجانية المسموح بها أو اختيار نموذج OpenRouter مدفوع.

**لا تضع مفاتيح API في الكود أو المحادثة أو سجلّات GitHub.**

## سلوك مسارات المجاني

- جميع طلبات التحليل واستخراج الوظائف والمراجعة المستقلة تمر عبر الدالة نفسها ذات المسارات المجانية.
- لا توجد مراجعة مستقلة على Astra أو Sol؛ تم حذف تكامل OpenAI من التشغيل.
- لا يستطيع مراجع APPLY ترقية قرار REVIEW أو REJECT إلى APPLY. وعند فشل المراجعة أو غياب الدليل الواضح، تبقى بوابة الأمان قائمة.
- `openrouter/free` يوجّه إلى نموذج مجاني. يرفض الكود معرّفات النماذج التي لا تنتهي بـ `:free` أو لا تساوي `openrouter/free`.
- لا تتجاوز أي جهة احتياطية حدود الاستخدام الخاصة بها؛ عند نفادها، يؤجّل JobFinder المعالجة ويحفظ المنشورات لإعادة المحاولة.

## متابعة حالة المزوّد داخل Telegram

يعرض أمر `/status` آخر مسار نجح فعليًا:
- `Gemini`: ردّ نموذج Gemini.
- `نموذج Gemini احتياطي`: تعذّر النموذج الأساسي وردّ نموذج Flash احتياطي.
- `Groq البديل`: تعذّر Gemini وعاد التحليل عبر Groq Free.
- `OpenRouter`: استُخدم مسار OpenRouter Free.
- `Groq فقط`: لا يوجد مفتاح Gemini مضبوط في بيئة التشغيل.

تظل حالة الاتصال الفعلية منفصلة عن مجرد وجود المفتاح؛ لا يثبت وجود Secret أن الخدمة متاحة أو أن الحصة لم تنفد.

## اختبار الاتصال دون إرسال طلبات توظيف

من **GitHub → Actions → JobFinder AI Provider Smoke Test → Run workflow** شغّل اختبار الاتصال عند الحاجة.

- يرسل الاختبار طلب JSON تجريبيًا فقط.
- لا يرسل بريد توظيف ولا يغيّر حالة الوظائف.
- يجب أن يوضح السجل المزود الذي أجاب فعليًا.
- إذا نفدت الحصة المجانية، يعرض الاختبار الخطأ ولا يحاول التحويل إلى مزود مدفوع.

## التدقيق والتقييم

التدقيق للقراءة فقط لا يرسل رسائل توظيف ولا يحفظ مؤشرات المعالجة، لكنه يستهلك حصص AI المجانية. لذلك شغّله عند الحاجة وبعينة صغيرة أولًا. التقييم يستخدم مزوّدات المجاني فقط، وقد يتوقف أو يؤجل حالات الاختبار عند بلوغ حدود الاستخدام.
